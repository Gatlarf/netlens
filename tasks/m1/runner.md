Create app/scanner/nmap_runner.py (stdlib only, asyncio).

- class ScanError(RuntimeError).
- def build_args(kind: str, targets: list[str], timing: int = 3) -> list[str]: returns the nmap argument list WITHOUT the executable name. kind is "quick" or "deep", else ValueError. Every target must satisfy app.config.is_scannable_range(target) or be a single private IPv4 address (use ipaddress; private or link-local only), else ValueError("invalid target: <t>"). Arguments: "quick" -> ["-T<timing>", "--top-ports", "100", "-oX", "-"]; "deep" -> ["-T<timing>", "-sV", "-O", "--osscan-guess", "--top-ports", "1000", "-oX", "-"]. Then the targets appended last. timing must be 0-5 else ValueError. Never build a shell string.
- async def run_nmap(kind: str, targets: list[str], *, nmap_path: str = "nmap", timing: int = 3, timeout: float = 3600.0) -> str: builds args, runs with asyncio.create_subprocess_exec(nmap_path, *args, stdout=PIPE, stderr=PIPE), waits with asyncio.wait_for. On timeout kill the process and raise ScanError("nmap timed out"). Non-zero exit raises ScanError with the last 500 chars of stderr. FileNotFoundError becomes ScanError("nmap not found"). Returns stdout decoded as utf-8 (errors="replace").
