Create app/static/js/app.js (ES module, the entry point). Imports: { get, post, ApiError } from "./api.js"; { clear, toast, el } from "./util.js".
Behaviour:
- Page modules live in js/pages/<name>.js and export async function render(container, params) returning an optional cleanup function (called before the next page renders). Routes by location.hash: "#/" or "" -> map; "#/map" -> map; "#/devices" -> devices; "#/device/<id>" -> device with params {id: Number}; "#/scans" -> scans; "#/settings" -> settings. Load page modules with dynamic import(`./pages/${name}.js`); if the import or render throws show a .card with the error message in the container instead of crashing. Unknown route -> devices. Update .nav-link.active by data-route on every navigation. Focus the #view container after navigation.
- Auth: on start call get("/api/session"); if not authenticated open the login dialog (#login-dialog, showModal). Submitting #login-form posts {token} to /api/login; on success close the dialog, clear the error and render the current route; on failure show the error text (ApiError.detail) in #login-error (unhide it). Listen for the "netlens:unauth" document event: open the login dialog (if not already open). The dialog must not be dismissable with Escape while unauthenticated (cancel event preventDefault). #logout posts /api/logout then opens the dialog.
- Scan controls: #scan-quick and #scan-deep POST /api/scans {kind}; on 202 toast "Scan started"; 409 toast "A scan is already running"; other errors toast the message. Poll GET /api/scans/current every 3 seconds while authenticated (start the interval after login, stop on logout/unauth); when running show "Scanning…" in #scan-status and disable both scan buttons, otherwise show "" and enable them. When a scan transitions from running to finished, dispatch document.dispatchEvent(new CustomEvent("netlens:scan-finished")) so pages can refresh.
- Re-render the current route on "hashchange".
